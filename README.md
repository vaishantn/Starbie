# Starbie ⭐

**Starbie** is a tiny motion-controlled digital pet, basically a desktop Tamagotchi. 
---
Starbie Features:
- Detect tilt, acceleration and shaking
- Senses the temperature and the humidity
- Nap
- You can play with it
- You can Feed it
- You can Pet it
- It has a status screen
